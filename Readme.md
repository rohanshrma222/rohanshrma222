## Hey there

I'm Rohan, an engineer from New Delhi building at the intersection of **web, AI, and open source**. I like real-time systems, developer tooling, and shipping things people can actually use.

Currently building my own coding agent CLI called Chime.

### My Journey So Far

- Maintainer at Palisadoes Foundation.
- Part of **Google Summer of Code '26**.

- Contribute to open source across TypeScript and Python projects, with **50+ merged pull requests** so far:
  - **[Nano Collective](https://github.com/Nano-Collective)**: shipped features for [nanocoder](https://github.com/Nano-Collective/nanocoder), an open, community-built terminal coding agent. I added a CI watch mode that investigates failures automatically, a headless PR review command, and PR diff, comment and CI log reading. I also work on [nanotune](https://github.com/Nano-Collective/nanotune), a CLI for fine-tuning small language models on Apple Silicon, adding benchmark comparison, MLX hyperparameter flags, and cache cleanup.
  - **[Palisadoes Foundation / Talawa](https://github.com/PalisadoesFoundation/talawa-admin)**: built calendar views (weekly, yearly), migrated UI to shared Dropdown and BaseModal components, and fixed UI regressions in the admin portal.
  - **[Moss](https://github.com/usemoss/moss)**: fixed Pipecat compatibility and kept integrations current (Mastra, n8n, Vite).
  - **[BillingSDK](https://github.com/dodopayments/billingsdk)** (Dodo Payments): contributed a pricing table component to this billing UI library (500+ stars).
  - **[Open Food Facts](https://github.com/openfoodfacts)**: API hardening and type generation for web components.

- Built **[ConvoCity](https://github.com/rohanshrma222/ConvoCity)**: a virtual office where avatars move around a 2D space and audio fades with distance, like a real room. Next.js, Phaser, LiveKit and Turborepo. [Live demo](https://convo-city-web.vercel.app).

- Built **[InkSync](https://github.com/rohanshrma222/InkSync)**: a real-time collaborative whiteboard in the spirit of Excalidraw, with shapes, arrows, freehand drawing, undo/redo and autosave. Next.js, Express, WebSockets, Prisma.

- Built **[scalable-chat-app](https://github.com/rohanshrma222/scalable-chat-app)**: a chat backend designed to scale horizontally with Redis, Kafka and PostgreSQL.
